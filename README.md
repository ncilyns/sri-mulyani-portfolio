# Sri Mulyani — Portfolio

Vite + React + TypeScript, siap deploy ke Vercel.

## Jalankan
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Struktur
- `src/data/content.json` — isi proyek, About, dan pengalaman (dari dokumen Word)
- `src/App.tsx` — halaman dan komponen
- `src/index.css` — desain, warna maroon, dan mode terang/gelap
- `public/img/` — screenshot dashboard, mockup, dan foto
- `public/docs/` — PDF, notebook (.ipynb dan .html), dan .drawio; dibuka lewat `/docs/...`

## Deploy di Vercel
Push ke GitHub, import di Vercel (preset Vite), lalu Deploy.
